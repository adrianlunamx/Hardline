# COMANDOS GIT PARA HARDLINE - GUÍA RÁPIDA

## PARA HACER PULL (ACTUALIZAR DESDE GITHUB):
1. powershell
2. cd "C:\Users\Adrian L\AppData\Local\Hardline"
3. git status                   # Ver estado
4. git add .                    # Guardar cambios locales
5. git commit -m "Mensaje"     # Confirmar cambios
6. git pull origin main        # Actualizar desde GitHub

## PARA VER INFORMACIÓN:
• git log --oneline            # Ver historial
• git remote -v               # Ver conexiones remotas
• git branch -a               # Ver todas las ramas
• git diff                    # Ver diferencias

## PARA SUBIR CAMBIOS (PUSH):
1. git add .
2. git commit -m "Cambios"
3. git pull origin main       # Actualizar primero
4. git push origin main       # Subir cambios

## SOLUCIÓN DE PROBLEMAS:

### "Your local changes would be overwritten"
# Guardar cambios primero:
git stash                     # Guardar temporalmente
git pull origin main         # Actualizar
git stash pop                # Recuperar cambios
# Resolver conflictos si los hay

### "Please tell me who you are"
git config --global user.name "Tu Nombre"
git config --global user.email "tu@email.com"

### "Authentication failed"
# Usar token de GitHub en lugar de contraseña
# O usar SSH keys
