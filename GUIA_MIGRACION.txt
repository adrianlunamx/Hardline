EJEMPLOS DE USO:
----------------
# Instalación con validaciones completas
.\install_seguro.ps1

# Prueba sin realizar cambios
.\install_seguro.ps1 -DryRun

# Instalación sin confirmaciones (solo para automatización)
.\install_seguro.ps1 -AcceptAll

# Limpieza completa con todas las confirmaciones
.\cleanup_seguro.ps1 -Mode All

# Limpieza simulada
.\cleanup_seguro.ps1 -DryRun -Mode Audio

PRUEBAS RECOMENDADAS:

2. Test de confirmaciones: Deberían requerir palabras exactas
3. Test DryRun: No debe realizar cambios reales

SISTEMA DE VALIDACIÓN DE URLS:
-----------------------------
El módulo url_validator.psm1 filtra URLs según:
• Dominios permitidos (whitelist)
• Extensiones de archivo seguras
• Protocolos permitidos (HTTPS preferido)
• Validación de certificados SSL
